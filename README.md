# 🌐 HTML-CSS - Curso em Vídeo

Este repositório reúne todos os projetos, exercícios e exemplos práticos que desenvolvi ao longo do curso de **HTML5 e CSS3** do professor **Gustavo Guanabara**, disponível gratuitamente no [Curso em Vídeo](https://www.cursoemvideo.com/).

---

## 📚 Sobre o repositório

Aqui você encontra minha jornada de aprendizado em **desenvolvimento web básico**, com foco em:

- Estruturação de páginas HTML
- Estilização com CSS externo, interno e inline
- Responsividade e boas práticas de layout
- Listas, tabelas, vídeos, fontes, ícones, links e muito mais!

Cada pasta do repositório representa uma aula ou módulo específico com arquivos de prática.

---

## 🧠 Aprendizados principais

✅ Tópicos abordados no repositório:

- 📄 Estrutura básica HTML (`<!DOCTYPE html>`)
- 🖼️ Imagens, listas e links
- 🎨 CSS interno, externo e inline
- 🆎 Tipografia, cores e fontes externas
- 📱 Responsividade com `@media` e `viewport`
- 📦 Box model, bordas, margens e padding
- 🧱 Divs, spans, agrupamentos e semântica
- 🎥 Vídeo, áudio e integração de mídia
- 🔗 Navegação entre páginas
- 🎯 Layouts com `display`, `flexbox` e `position`
- 🖌️ Personalização visual e identidades
